# PHP Demonstration Programs

These five examples show course concepts in a successful run. Copy the source into MPLab and select PHP. Only `success.php` needs an input value.

| Program | Concept | Input | Expected output |
| --- | --- | --- | --- |
| `success.php` | Standard input and integer conversion | `7` | `Double of 7 is 14` |
| `dynamic_types.php` | Dynamic typing | | `int` then `string` |
| `array_loop.php` | Associative arrays and `foreach` | | `Total: 10` |
| `parameters.php` | Default arguments and pass-by-value | | `With fee: 12` then `Original: 10` |
| `static_scope.php` | Static local variable lifetime | | `Ticket 1` then `Ticket 2` |

The classroom API demo also uses `syntax_error.php` to show a missing semicolon and `runtime_error.php` to show division by zero. Both errors appear on line 3.
